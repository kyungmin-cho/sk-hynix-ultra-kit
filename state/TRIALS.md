# TRIALS — 시행 등록부

> 이 파일이 있으면 시행은 여기에 적는다(없으면 `notes/DECISIONS.md` §2). 숫자 없이 채택하지 않는다.
> n=0은 기준선. 모든 시행은 n=0과 **같은 평가 구간·같은 지표**로 잰다. 시행은 자기 폴더 `exp/<n>/`에만 쓴다.

| n | 가설 | 경로 | 명령 | 지표(수치) | 결과(기준선 대비) | 채택/폐기(이유) |
|---|---|---|---|---|---|---|
| 0 | 기준선: | exp/0/ | | | — | 기준 |
| 1 | | exp/1/ | | | | |
| 2 | | exp/2/ | | | | |

## 시행 규칙 (짧게)

- 동시 시행 수 = min(2, PAR_MAX, STATE `PAR_NOW`). 시행마다 `OMP_NUM_THREADS` = max(1, NPROC // 동시 수).
- 실행은 가능하면 `bash <H>/scripts/run_and_log.sh trial<n> -- <명령>` → 로그 경로를 "명령" 칸에 같이 적는다.
- 10분 막히면 폐기하고 이유 한 줄. 폐기한 시행도 지우지 않는다(서술형 "다시 한다면" 재료).

## exp/<n>/RESULT.md 4줄 형식

```text
가설: <무엇을 바꾸면 무엇이 좋아지나>
명령: <그대로 복붙 가능한 명령>  (로그: logs/<파일>)
지표: <지표 이름>=<수치> (기준선 n=0: <수치>, 평가 구간: <구간>)
결론: 채택 | 폐기 — <이유 한 줄>
```
