# ESSAY_PREP — 서술형 재료

> 이 파일이 있으면 서술형 재료는 여기에 적는다(없으면 `notes/HANDOFF.md` §5).
> 서술형 답은 **사람이 직접** 친다(AI·복붙 금지). 여기에는 재료만: 수치·결정·근거 경로. 기록에 없는 것은 "기록 없음".
> 답 골격: 사실 → 결정 → 근거(수치) → 한계.

## 1. 단계별 3줄 (수치 1개 이상 포함)

| 단계 | ① 사실(수치) | ② 결정과 대안 | ③ 근거 경로 |
|---|---|---|---|
| 1 환경 | 예: NPROC=?, 유효 메모리 ?GB, pandas ?, PyPI ? | | ENVIRONMENT.md 꼬리표, DECISIONS §1 |
| 2 문제 | | | notes/TASK.md |
| 3 점검·E2E | | | |
| 4 시행 | 기준선 ? → 채택안 ? | | TRIALS / DECISIONS §2 |
| 5 수합 | PASS ?/FAIL ?/NOT_RUN ? | | VERIFICATION / DECISIONS §3 |
| 6 최종 | | | HANDOFF §1 |

## 2. 약점 → 파급 → 다음 검증

## 3. 예상 질문 6개와 답 재료

| # | 예상 질문 | 답 재료(수치·결정) | 근거 파일 경로 |
|---|---|---|---|
