# 서버·미리보기

- 바인딩은 항상 `0.0.0.0`, 포트는 환경변수로: `PORT="${PORT:-8000}"`. `localhost`/`127.0.0.1`만 바인딩하면 미리보기에서 안 보인다.
- 서버는 **사람이 IDE 터미널에서** 띄운다(에이전트 샌드박스 안에서는 소켓이 막히거나 승인 창이 반복될 수 있다). 에이전트는 실행 명령 한 줄만 알려 준다. 예: `PORT=8000 python3 app.py`.
- 미리보기: 플랫폼의 Browser/미리보기 탭에 같은 포트 번호를 입력해 연결한다(사람이 화면으로 확인).
- ENVIRONMENT.md에서 `SOCKET=denied`이거나 서버가 안 뜨면 **정적 HTML 폴백**: 결과를 `out/report.html` 같은 파일로 만들고 표·수치를 HTML에 직접 넣는다(외부 CDN 의존 없이).
- 서버와 상관없이 핵심 결과는 **파일로도** 남긴다(CSV/JSON). 검사는 서버가 아니라 이 파일로 한다.
- 작업 환경이 pause·재연결되면 서버만 다시 띄운다. 오래 걸리는 계산은 결과를 파일에 캐시해 재시작이 빠르게.
- 모듈: `templates/web/` (stdlib http.server + HTML 폴백). 필요한 함수만 옮긴다.
- 미리보기가 안 열릴 때 확인 순서: ① 서버가 `0.0.0.0`에 떴나(시작 로그) ② 포트 번호가 미리보기 입력과 같나 ③ 프레임워크가 Host 헤더를 막나(개발 서버의 허용 호스트 설정) ④ 그래도 안 되면 10분 규칙 → 정적 HTML.
- 서버 시작 명령은 HANDOFF §1과 README에 그대로 적는다(재연결 후 사람이 다시 띄울 수 있게).
