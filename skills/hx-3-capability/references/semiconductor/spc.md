# SPC·수율 해석 원칙

> 코드: `templates/spc/spc.py`(`imr_fit`/`imr_apply`, `western_electric`, `xbar_r_fit`, `cp_cpk`), `templates/yield_/groupstats.py`.
> 필요한 함수만 옮기고 DECISIONS에 "가져온 함수·무엇을 바꿨나"를 적는다.

## 관리도 고르기

| 데이터 | 관리도 | 한계 |
|---|---|---|
| 시점마다 값 1개(웨이퍼당 측정 1개 등) | I-MR | 중심 ± 2.66 × MR평균 (σ = MR평균 / 1.128) |
| 시점마다 같은 크기 부분군 2~10개 | Xbar-R | 중심 ± A2 × R평균 |
| 불량 개수·비율 | p / np 관리도(템플릿 없음, 직접 작성) | 표본 크기가 다르면 한계도 달라짐 |

## 단계와 기준선

1. **기준 구간(Phase I)**: 담당자가 "정상"이라고 한 기간 또는 데이터 앞부분. 최소 20~25점. 기준 구간 안의 명백한 이상점은 이유를 적고 빼서 다시 계산한다.
2. **한계 고정**: 기준 구간으로 구한 중심·σ를 고정한다.
3. **감시 구간(Phase II)**: 고정 한계로 판정만 한다. 감시 구간 값으로 한계를 다시 계산하지 않는다(이상점이 한계를 넓혀 스스로를 숨긴다).
4. 기준 구간을 어떻게 정했는지 DECISIONS에 한 줄(기간·점 수·뺀 점과 이유).

## Western Electric 규칙 (위반 = 조사 후보)

| 규칙 | 조건 | 흔한 뜻 |
|---|---|---|
| 1 | 1점이 3σ 밖 | 돌발 사건 |
| 2 | 연속 3점 중 2점이 같은 쪽 2σ 밖 | 수준 이동 시작 |
| 3 | 연속 5점 중 4점이 같은 쪽 1σ 밖 | 작은 시프트 |
| 4 | 연속 8점이 중심선 한쪽 | 지속적 치우침·드리프트 |

- 규칙을 많이 켤수록 오경보가 늘어난다. 어떤 규칙을 켰는지 결과에 같이 적는다.
- 자기상관이 강한 센서(초 단위 트레이스)는 규칙이 과하게 걸린다 → 웨이퍼·스텝 단위 요약값에 적용하거나 담당자와 정한다.

## 공정능력 Cp / Cpk

- Cp = (USL − LSL) / 6σ, Cpk = min(USL − 평균, 평균 − LSL) / 3σ. 한쪽 규격만 있으면 그쪽만.
- σ는 군내 σ(I-MR의 MR평균/1.128)인지 전체 표준편차인지 밝힌다(값이 달라진다).
- 관리 상태가 아닌(규칙 위반이 많은) 공정의 Cpk는 의미가 약하다 → 먼저 관리도.
- 1.33·1.67 같은 기준은 업계 관행. **담당자 기준이 우선**.

## 수율·불량 요인

- 집계 전에 검사: 키 중복, 결측, `passed > tested`, 음수 → 오류로 세서 보고(조용히 버리지 않음).
- 요인별 불량률은 표본 수와 같이. 기대도수 5 미만 칸이 많으면 카이제곱 p값을 믿지 않는다.
- "장비 A의 불량률이 높다"는 공통성 신호일 뿐. 같은 기간 다른 요인(제품·레시피·시간대)이 섞였는지 교차표로 확인한다.
- 수율은 웨이퍼 평균의 평균이 아니라 총 양품 ÷ 총 시험 수로(가중 평균). 어느 쪽인지 문서에 적는다.
