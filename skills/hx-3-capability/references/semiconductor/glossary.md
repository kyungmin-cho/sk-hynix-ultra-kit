# 반도체 용어 (과제 문서·담당자 말 해석용)

> 지식만 담는다. 코드는 `templates/`에서 필요한 함수만 옮긴다. 과제 문서·담당자의 정의가 이 표보다 우선이다.
> 해석 원칙은 `patterns.md`, 관리도·공정능력은 `spc.md`.

## 제품·단위

| 용어 | 뜻 | 데이터에서 보이는 모습 |
|---|---|---|
| 웨이퍼 / 로트(lot) | 칩을 만드는 원판 / 함께 공정을 도는 웨이퍼 묶음(보통 25장) | `lot_id`, `wafer_id`(로트 안 슬롯 번호) |
| 다이(die) / 넷 다이 | 웨이퍼 위 칩 하나 / 웨이퍼당 칩 수 | 다이 좌표 `x,y`, 웨이퍼당 수백~수천 행 |
| 수율(yield) | 양품 수 ÷ 전체 수. 단계별(라인·프로브·패키지) | `tested`, `passed` 또는 다이별 합불 |
| 빈(bin) | 테스트 결과 분류 코드(1=양품이 흔하지만 회사마다 다름) | `bin`, `hbin`/`sbin` |
| 웨이퍼맵 | 웨이퍼 위 다이별 합불 공간 패턴(가장자리·링·스크래치·중앙 등) | 다이 좌표 + 합불 |
| DPPM / 불량률 | 백만 개당 불량 수 / 불량 수 ÷ 전체 수 | 집계 표 |

## 공정·장비

| 용어 | 뜻 | 데이터에서 보이는 모습 |
|---|---|---|
| 공정 단계(step) | 식각·증착·노광·CMP·세정·이온주입 등 순서 | `step`, `oper`, `route` |
| 장비 / 챔버 | 같은 단계를 하는 장비 여러 대, 장비 안의 챔버 여러 개. 챔버별 차이가 흔한 요인 | `eqp_id`, `chamber` |
| 레시피 | 장비 설정값 묶음 | `recipe` |
| PM | 예방 정비. 전후로 신호 수준이 바뀌는 경우가 많다 | 이벤트 로그의 PM 시각 |
| 시즌(seasoning) | PM·세정 직후 안정화 구간 | PM 직후 몇 로트 |
| FDC | 장비 센서 신호로 공정 이상을 감지·분류 | 센서 트레이스(시각×센서) 또는 요약값(평균·최대) |
| 트레이스 / 요약 통계 | 공정 중 초 단위 센서값 / 웨이퍼·스텝당 평균·최대·기울기 | 긴 형식(long) 또는 넓은 형식(wide) |
| 계측(metrology) | 두께·CD(선폭)·오버레이 등 측정 | `thk`, `cd`, `ovl` |
| 전기 특성 검사 | 웨이퍼 상태에서 전기 특성 측정 | 파라미터 수십~수백 열 |
| 프로브 테스트 / 최종 테스트 | 웨이퍼 상태 다이 테스트 / 패키지 후 테스트 | 빈·합불 |

## 통계·관리

| 용어 | 뜻 |
|---|---|
| SPC / 관리도 | 공정 통계 관리 / 중심선·관리 한계(보통 ±3σ)로 이탈 감시 |
| I-MR | 개별값·이동범위 관리도(부분군이 1개일 때) |
| Xbar-R | 부분군 평균·범위 관리도(부분군 크기 2~10) |
| Western Electric 규칙 | 1점 3σ 밖, 2/3점 2σ 밖, 4/5점 1σ 밖, 8점 한쪽 등 이탈 규칙 |
| USL / LSL | 규격 상한 / 하한(고객 요구). **관리 한계(UCL/LCL)와 다르다** |
| Cp / Cpk | 규격 대비 공정 능력 / 중심 치우침까지 반영한 능력 |
| 드리프트 / 시프트 | 서서히 변함 / 갑자기 수준이 바뀜 |
| OOC / OOS | 관리 한계 이탈 / 규격 이탈 |
| 공통성 분석(commonality) | 불량 웨이퍼들이 공통으로 거친 장비·챔버·시간대를 찾는 분석 |
